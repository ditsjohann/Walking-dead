# Phase 7: Groningen's buildings. Standing in a pharmacy, a police station and the UMCG (projected
# from OpenStreetMap onto the default Groningen box), /outbreak place names the building and a chest
# there fills from that building's list. Out in a field, a chest goes by the room as before.
== setup
gamerule spawn_mobs false
time set noon
player Bot spawn at 0 -57 0
wait 3
gamemode survival Bot
== a pharmacy: expect "In a pharmacy" and its loot
forceload add 6632 6933 6648 6949
tp Bot 6640 -57 6941
wait 2
execute as Bot at @s run outbreak place
setblock 6642 -57 6941 minecraft:chest[facing=west]
player Bot look at 6642 -56.5 6941.5
player Bot use once
wait 1
data get block 6642 -57 6941 Items
forceload remove 6632 6933 6648 6949
== a police station: expect "In a police station" and its loot
